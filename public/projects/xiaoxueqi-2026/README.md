# Xiaoxueqi Intelligent Connected Vehicle Showcase

This directory contains public materials collected from the local `xiaoxueqi-2026` project folder.

## Contents

- `showcase-site/`: static showcase site source, including HTML, CSS, JavaScript, project data, and images.
- `photos/`: project photos for hardware, software, and game groups.
- `videos/`: the project showcase recording found locally.

The static showcase can be opened at `/projects/xiaoxueqi-2026/showcase-site/index.html` after deployment.

## Notes

- Original archives, caches, extraction logs, and the DingTalk group QR code were excluded.
- No matching `.ppt` or `.pptx` files, or complete group project source trees, were found in the local workspace. They were not fabricated or substituted.
- Some links inside the preserved showcase data refer to source files outside this collection and may not be available.
