# 智能网联成果展交付说明

本目录是根据当前文件夹内 9 个小组的小学期资料整理出的静态成果展示站和招新海报。

## 文件

- `index.html`：成果展示网站入口，支持按方向筛选、关键词搜索、项目详情弹窗、图片画廊、演示视频和原始资料索引。
- `招新海报.png`：适合直接转发或打印的 PNG 海报。
- `招新海报.svg`：矢量海报，可继续编辑或用于高质量印刷。
- `成果分析.md`：分组分析、展示策略和招新传播建议。
- `assets/dingding-qr.png`：钉钉群二维码。

## 打开网站

最简单的方式：直接双击 `index.html`。

如果需要在局域网中展示，建议在当前文件夹（与“智能网联成果展”同级）打开终端运行：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/智能网联成果展/`。

网站中的“资料索引”会回到上一级目录打开各组提交的 PPT、DOCX、视频和工程文件；请不要移动 `智能网联成果展` 与各组文件夹之间的相对位置。

## 内容说明

网站项目卡片根据各组报告/PPT中的项目名称、主要工作、功能表和演示材料整理而成；图片优先取自汇报 PPT 内嵌图片，视频保留原始文件路径。所有统计截至 2026 年 9 月 21 日。
