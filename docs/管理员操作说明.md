# car_lab 管理员操作说明

管理员日常使用 Vue `/admin` 工作台。PocketBase `/_/` 仅用于受控初始化和维护，不作为日常业务入口。

## 登录与退出

1. 从 `/portal?mode=login` 使用学号或用户名登录。
2. 管理员登录后进入 `/admin`；普通成员访问该路径会被送回成员中心。
3. 操作结束后点击“退出登录”。不要在聊天、日志或截图中记录密码和 token。

## 申请与成员

- 在“申请审核”中按姓名、学号、用户名、团队和状态筛选申请。
- 只有 `pending` 申请可以通过或拒绝；重复审核会被拒绝。
- 在“成员管理”中停用或恢复学生账号，必要时通过受控密码重置流程设置临时密码。
- 在“团队成员关系”中独立撤销或恢复某个成员与团队的关系；撤销后该团队资源立即不可读。

## 资源

- 创建资源时填写团队、访问范围、标题、摘要和正文；摘要不得包含受限正文。
- 使用草稿状态保存尚未准备好的内容，确认后再发布。
- 公开资源可被访客读取；团队资源只对启用且已通过对应团队审核的成员开放；管理员资源只对管理员开放。
- 上传附件前核对文件类型和大小。附件超过 30 MiB 或 MIME 与扩展名不一致时应被拒绝。
- 替换、移除附件或下线资源后，重新打开详情确认访问结果和公开列表状态。

## 项目、公告与官网内容

- “项目成果”支持草稿、发布、下线，以及历史素材引用和受控素材上传。
- “新闻公告”先保存草稿，确认正文和摘要后再发布；下线后公开页面不可见。
- “官网内容”按区块编辑有效 JSON。保存前核对品牌、导航、页脚、首页和联系方式内容。
- “操作日志”用于核对审批、权限、资源、项目、公告和内容变更，不记录密码、token 或申请正文。

## 在线上传视频与成果文件

1. 进入“项目成果”，新建并保存项目，或编辑已有项目。
2. 在“受控项目素材”中，选择“视频”或“成果文件”，填写素材名称，将“来源”设为“上传文件”。
3. 选择文件并点击“添加素材”。单个文件不超过 30 MiB；视频支持 MP4、WebM、QuickTime，成果文件支持 PDF、Office、ZIP、纯文本等允许类型。
4. 上传默认不发布。确认内容后编辑该素材，勾选“对外发布”并保存；项目本身也必须已发布，访客才能访问。
5. 在公开“项目成果”页面打开项目详情，检查视频或成果链接。需要撤回时，在管理页对该素材点击“下线”，公开链接随即失效。

历史视频和成果原件可以日后通过此入口补录，无需先批量迁移才能使用。替换文件后需要再次确认并发布。

## 异常处理

遇到权限错误、附件下载失败、数据状态异常或重复写入时，先保留页面提示、时间和对象 ID，再联系维护负责人。不要直接修改数据库、删除 `pb_data` 或绕过受控接口写入集合。
