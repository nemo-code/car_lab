# car_lab 上线检查表

这份清单用于正式切换前的逐项核对。当前仓库只完成本地与隔离环境验证，未执行生产迁移、部署、域名切换或旧目录清理。

## 身份与范围

- [ ] 确认发布提交、构建产物和 PocketBase 版本均与本次验收证据绑定。
- [ ] 确认目标主机、服务账号、域名、维护窗口和回滚负责人。
- [ ] 确认旧 Node/SQLite 服务仍可恢复，且不与新服务共用 Session 或文件目录。

## 代码与构建

- [ ] `npm test` 全部通过。
- [ ] Node/SQLite 回滚产物使用 `VITE_PLATFORM_BACKEND=node npm run build` 构建并保存摘要；这是默认开发和回滚链路。
- [ ] PocketBase 发布产物使用 `VITE_PLATFORM_BACKEND=pocketbase VITE_POCKETBASE_URL=/api npm run build` 构建并保存摘要；该产物只能配合将 `/api/` 转发到 PocketBase 的代理配置。
- [ ] 从构建产物核对实际后端选择，并用匹配的 Node 或 PocketBase 流程完成浏览器验收；不能用 Node 产物配 PocketBase 代理，或反向混用。
- [ ] `npm run browser:e2e` 通过。
- [ ] `npm run browser:smoke` 在已启动的临时服务上通过桌面和 390px 视口检查。
- [ ] 在隔离服务上按目标参数运行 `CAPACITY_REQUESTS=<数量> CAPACITY_CONCURRENCY=<并发数> npm run capacity:smoke`，保存 p50/p95/最大延迟和失败请求；默认只允许回环地址。
- [ ] 固定 PocketBase 二进制版本与 SHA-256 已核对，未使用 `latest`。

## 数据与迁移

- [ ] 对旧 SQLite 和旧媒体制作一致性备份，保留 WAL 相关文件。
- [ ] 运行迁移预检，所有重复、孤立、非法字段和关系问题均有处理记录。
- [ ] 生成脱敏 `legacy_id → target_id` 映射并保存校验值。
- [ ] 在隔离目标执行两次导入，第二次不产生重复写入。
- [ ] 抽样核对管理员、待审、已通过、已拒绝账号及三个团队。
- [ ] 确认旧密码哈希和旧 Session 未被直接导入。

## 权限与文件

- [ ] 匿名、待审成员、跨团队成员不能读取受限正文或附件。
- [ ] 同团队已通过成员可以读取授权正文和附件。
- [ ] 停用账号、撤销 membership、过期或错误 token 均不能继续访问。
- [ ] 不带 token 直接访问受保护文件 URL 被拒绝；有效 token 的授权读取仍然成功。
- [ ] 错误 token、过期 token、停用账号或撤销 membership 后的 token 均被拒绝；不能把正常授权读取误判为失败。
- [ ] 直接访问 `pb_data` 或受保护文件存储路径均被拒绝。
- [ ] 合法文件、非法 MIME、扩展名伪装和超过 30 MiB 文件的结果符合预期。

## 部署与运行

- [ ] PocketBase 仅监听环回地址，数据目录不在 Web 根目录。
- [ ] Nginx 已配置 HTTPS、安全响应头、`/api/realtime` 长连接和 32 MiB multipart 上限。
- [ ] `/_/` 管理入口已通过 VPN、IP 白名单或安全隧道限制来源。
- [ ] systemd 使用固定二进制、专用低权限账号和明确的可写目录。
- [ ] 健康接口、登录、申请、审核、资源上传下载和错误日志均已现场复验。
- [ ] 按目标主机的实际账号规模、并发登录量、附件大小和磁盘配额完成容量与并发实测，并保存结果；本地功能测试不能替代该验收。
- [ ] 备份恢复演练已完成并记录结果。

## 切换后观察

- [ ] 观察登录、审核、附件下载、移动端页面和服务错误日志。
- [ ] 保留旧代码、旧数据库、旧媒体和旧代理配置，直到完成稳定期复核。
- [ ] 任何回滚均先导出并核对切换期间新增数据，不直接覆盖新数据。
