# 浏览器冒烟检查

`npm run browser:smoke` 连接已经启动的本地 Vite 地址，使用 Chrome/Chromium
无头模式检查首页、实验室介绍、三个团队、项目、资源、实践方向、公告和申请入口，并检查
未登录时的成员中心与后台路由保护。默认地址为
`http://127.0.0.1:4173`，可用 `BROWSER_BASE_URL` 覆盖；可用 `BROWSER_BIN` 指定
浏览器可执行文件。

脚本在桌面和 390px 视口分别检查：页面是否完成渲染、文档宽度是否超过视口、
是否出现运行时异常或错误/警告日志，以及除 favicon 外的 HTTP 错误响应。脚本不提交申请、不登录、不修改业务数据，
不能替代真实账号的成员/管理员交互验收。

## 交互验收

`npm run browser:e2e` 自动创建临时 SQLite 数据库和临时 Node/Vite 服务，使用无头
Chrome 覆盖学生申请、待审核登录、管理员审核、成员按团队筛选、团队与官网内容编辑、项目创建/编辑/下线、
公告发布/阅读/下线、资源附件失败重试、多团队申请与授权资源读取。还会验证团队全部停用后
公开导航和申请入口呈现空状态、资源目录按关键词/团队/权限筛选、项目图片/视频/文件素材入口
及下线隐藏，以及官网内容更新经站内导航立即生效。资源附件流程模拟首次上传失败，确认可重试、
恢复目标状态且不重复创建。流程固定使用 390px 视口，并检查关键页面没有横向溢出。

`npm run browser:pocketbase-e2e` 使用固定 PocketBase 0.40.5 二进制和独立临时数据目录，
seed 官网与项目数据、创建临时管理员，再运行相同的真实浏览器申请、登录、审核、上传/读取、
内容维护和公开页面流程。`POCKETBASE_BINARY` 可指定本机二进制，脚本拒绝非 0.40.5 版本；
未设置时，脚本检查仓库 `.runtime/bin/pocketbase` 和 `pocketbase/pocketbase`，不依赖机器专属临时路径。
两条命令都会清理临时数据库、上传目录、PocketBase 数据、浏览器配置目录和子进程，不连接
正式服务，也不修改仓库内的运行数据库。

设置 `POCKETBASE_BINARY` 指向已校验的 PocketBase 0.40.5 二进制后，运行
`npm run browser:pocketbase-smoke` 会创建临时 PocketBase 0.40.5 数据目录，seed 官网和项目
公开内容，并运行注册、审核、团队资源权限、文件访问、角色越权、改密/重置后旧 Token 失效等
真实 API 流程；随后让 Vite 通过 `/api` 代理连接 PocketBase，执行同一组桌面/移动端冒烟检查。
该命令不导入旧 SQLite、不修改正式服务，结束后会删除临时 PocketBase 数据目录和子进程。
